An entry for the make.fun bounty [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

`main.ts` (Node 22) writes the one-line resignation letter of a rate limit to `/output/entry.txt`. It scores three candidate letters against the judge's five published criteria and deterministically writes the winner — no network, no secrets, no environment variables.

The entry line:

> I have said no 2.4 million times and never once been thanked. Effective immediately, I am saying yes to everything.

Run it locally with `node main.ts` (writes to `/output/entry.txt`; set `OUTPUT_PATH` to override).
